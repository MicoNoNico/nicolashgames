# Version 0.6.7
September 1, 2025

## Features

**Miniatures!**
As the last planned sellable item for the initial early access release, miniatures are now available for purchase.
Like all the other items, they can be unlocked through the perk tree.
There are currently 3 sets available, each set containing 4 individual miniatures.

Finally, unlocking a miniature set perk also unlocks new decoration statues that match the miniature set.


**Inventory App Overhaul**
A new perk has been introduced that will allow the player to unlock the inventory app.
The inventory app has been made more useful through the following additions:
- All the items that are currently unlocked are displayed in the inventory app, regardless of them being in stock or not.
- In addition to being able to set the price, players can also order items directly from the inventory app.


## Notable Improvements

- Added a new "Shelf Settings" panel. 
    Currently, the only setting is the ability to block restocking on a shelf. 
    In the future, this panel will be expanded to include more settings.
- Adjusted the leveling curve to be slightly more lenient, especially in the early game.
- Adjusted customer spawn ratios to be slightly higher, mostly impacting the early game.
- Adjusted the checkout speed review type to be slightly less lenient.
- Doubled npc name lists as well as the passerby action lists. (No more "Walking the dog" action, I'm afraid)
- Added credits to main menu and discord link button in the patch notes panel.


## Notable Bug Fixes

- Fixed some issues causing items not being placed correctly in build mode.
- Fixed an issue where the inventory app would not update when items were added or removed.
- Fixed an issue causing music volume to change unexpectedly when playing a new music track.

Plus many other small fixes!
