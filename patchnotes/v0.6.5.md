# Version 0.6.5.h1
August 24, 2025

## Notable Improvements

- Added neutral reviews. This makes it so if values are only slightly negative/positive, customers will instead leave a neutral review.
- Slightly boosted plant decoration value.
- Made variety reviews a little more lenient for early game.
- Made litter chance code more reliable.
- Added a 20s cooldown for customer litter chance (Chance roll every 20s).
- The checkout can now be moved even if there are customers in the queue.
- The player can now take over a checkout from cashier workers, causing them to go idle.
- Added sound fx for right-clicking on npcs.
- Added a "max buy attempts" value to customers. This is to reduce the store's overcrowding.

## Notable Bug Fixes

- Fixed a value mismatch for decor score of clearing trash piles.
- Fixed an issue that prevented workers cleaning not counting towards the decor score.(Trash piles would add permanent impact)
- Fixed in-game guide not scaling well in ultra-wide resolutions.
- Fixed the customer info panel overlapping when in build mode.
- Fixed an issue preventing wall and floors from being saved correctly.
- Fixed transparent walls not being set back to customized material.
- Fixed an issue that would reset the wall/floor materials even if purchased.
- Fixed an issue with some walls not turning transparent when the player is behind them.
- Fixed an issue preventing staff live actions from being displayed in the info panel.
- Greatly improved staff spawning mechanics, making them less prone to issues.
- Fixed an issue causing the workers to not drop the broom when fired.
- Fixed an issue causing the workers to leave with the broom in hand when the day ended.
- Fixed an issue that would keep a box highlighted by the player when picked up by the staff.
- Fixed an issue that would make stolen items be ignored by the Inventory manager, resulting in negative values.
- Temporarily removed outline to selected npcs. (*This will be re-enabled in a future patch*)
- Fixed an issue with control popup bindings not updating after rebinding a key.
- Fixed an issue preventing the player's highlighted object not resetting when going back to menu.


# Version 0.6.5
August 20, 2025

## Features

**Global Market**
There is a new app in the phone interface called "Global Market".

- With this app, players can now visualize the demand for every item in the game.
- Customers are a lot more likely to buy items that are in high demand.
- The demand varies every in-game day, so make sure to check back before planning your restocks.


**In-game Guide** 
You can now access a series of in-game guides from the settings or from buttons marked with a question mark.

The new guides include mechanics that are not covered in the initial tutorial, such as:
- Staff Management
- Store Rating
- Global Market
- Cleaning the Store
- Thieves


## Notable Improvements

- Add pulse animation to the build button counter when new furniture is deposited on the pallet.
- Updated cursor graphic.
- Reduced staff speed perk increment from 0.5 to 0.4. (They were zooming a little too much.)
- Added checkout "reservation" to avoid multiple cashiers going to the same checkout.
- Added "Item Stands" to shelves to display the item assigned.
- Added salary info to the Staff app in the phone.
- Added hover and scale animations to the cashier interface.
- Added more info to the cart items list as well as buttons to remove/add 1 item at a time.
- Added the option to order empty boxes.
- Overhauled player customization interface and added more options.
- Staff now wear similar clothing.
- Every npc can now be right-clicked to view their information.


## Notable Bug Fixes

- Fixed an issue that prevented player movement after going back to menu.
- Fixed the body type 2 prefab not turning walls transparent when behind them.
- Added missing control popups for the broom.
- Fixed a bug that would make it so changing the wall color would also change the pallet.
- Fixed an issue that would make the player be able to call two trucks with the same load.
- Fixed an issue that would bypass the player set sound settings for the thief chase music.
- Fixed an issue that would make customers skip the queue and immediately upload items to the checkout.
- Fixed an issue that would prevent re-hiring staff if fired on the same day.
- Fixed an issue that would allow customers to purchase more items than the allowed maximum.
- Added several checks and fail safes to prevent customers from leaving with items when the store is closed. (99% patched, still some edge cases.)
- Fixed some texture flickering where road tiles connect.
- Fixed an issue that would prevent the initial shelf from being able to be sold.
- Prevented being able to enter build mode while main UI panels are open.
- Fixed an issue that would keep a shelf as interactable if it was moved while the player was in focus range.
- Made broom control popups appearance more accurate.
- Resized player interaction collider to be more accurate (maybe, tbh).
- Fixed an issue that prevented utilities and salaries expenses from bringing the balance below 0.
- Fixed an issue that would break the game on game over.

And many, many more small fixes!
