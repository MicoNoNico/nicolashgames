# Version 0.6.9
October 14, 2025

*Thanks to everyone who has been submitting bug reports, they are a huge help!*


## Features

**Better Box Categories**
Players can now select their preferred box size directly before adding an item to the cart.
In the Restock app, only individual items and their market value are now being displayed, reducing clutter from displaying multiple boxes of the same item.
It is now also possible to select larger box types when ordering from the Inventory app.

**More Wall and Floor customization**
Added 2 more wall texture types with different color options.
Added a brick wall type.
Added 6 more floor types.
*This is not the final list of available store customization. I will keep updating/refining these in future updates!*


## Notable Improvements

- Customers now (mostly) give more realistic amounts of cash when paying, without overshooting.
- Added a tooltip popup when attempting to grab a broom already reserved by a worker.
- Added large boxes (10% discount) for the booster box items.
- Added more info to the store review guide page.


## Notable Bug Fixes

- Fixed an issue that would make the customers ignore their cash reservers when considering what to purchase.
- Fixed an issue preventing purchasing from the inventory app.
- Fixed an issue preventing the store rating from being correctly reset when starting a new save.
- Fixed the "Starter" booster box having "Champion" written on the model.
