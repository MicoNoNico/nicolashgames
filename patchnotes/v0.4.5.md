# Version 0.4.5.h2
February 19, 2025

## Notable bug fixes & improvements

- Can now fire staff even when they haven't spawned yet.

- The inventory furniture panel is now disabled while in sell mode.

- Fixed an issue where the purchase button in the store expansion panel would remain active after a purchase was made.

- Fixed an issue where customers would upload items to the checkout's UI even when the checkout was unmanned or manned by an AI.

- Fixed an issue where cashier workers would process multiple checkout queues at once.

- When the player leaves the checkout UI before having scanned all items, the items will now reset. Additionally, the player is now not allowed to leave the transaction after having scanned all items.

- Reduced checkout object's collider for slightly easier placement options.

- Shelves are now claimed by restock workers to prevent multiple workers going to the same one (This partially works, will need further iteration).


# Version 0.4.5.h1
February 17, 2025

## Features

**Patch Notes Viewer**
You can now view the latest patch notes directly from the main menu.


## Notable bug fixes & improvements

- Fixed broom duplication bug when going back to menu and loading another save.

- Holding a broom now prevents all other interactions (besides sweeping).

- Customers now have a set chance to leave a review (instead of always).

- Fixed customers getting stuck in a pondering loop when shelves are found empty.

- Reworked checkout priorities. If more than one checkout is present, customers will now prioritize the one with the smallest queue.

- All popup panels can now be closed by pressing [ESC] (set price, warehouse, cashier).

- Balanced store expansion costs to be more expensive.

- Disabled player movement input while typing (console or store renaming).


# Version 0.4.5
February 15, 2025

## Features

**Reviews & Store Rating**
The store now has a rating ranging from 1 to 5 stars. The store's rating will impact the amount of customers you receive every day.

Customers now will leave reviews after leaving the store. The reviews left will impact the store's rating the next day.

Review types currently include: 
- Finding empty shelves (negative)
- Queue full at checkout for too long (negative)
- Checkout speed (positive or negative)
- Store item variety (positive or negative)
- Store decoration/cleanliness (positive or negative)

**Store decorations & littering**
Customers now occasionally litter around the store while walking around. The player can use the broom to clean up the dust piles.

**Decoration furniture!**
Both decoration furniture and litter have an impact on reviews.

**Inventory Manager**
Players can now view their entire store's item inventory from the phone. All the items that are currently in the store are shown, specifying which are on shelves and which are stored in boxes.


## Notable bug fixes & improvements

- Storage workers can now pick empty boxes from warehouses and throw them out (Before they would only throw out boxes found on the ground).

- Restock and storage workers now "claim" boxes before going to them. This avoids workers going to the same box.

- Store name now allows alphanumeric values.

- Instead of having a fixed number of buy attempts, customers now spawn with a certain amount of money they are willing to spend, resulting in more dynamic buy attempts.

- All object colliders have been adjusted for extra breathing room when dragging. This means that objects like the checkout will not allow other objects to be placed adjacent to it.
