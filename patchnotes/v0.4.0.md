# Version 0.4.0
January 24, 2025

## Features

**Store Staff**
Hire employees to work various jobs inside the store.

Current job types:
- Cashier. Cashiers will handle the checkout queues in your stead.
- Storage. Storage workers will handle moving boxes to warehouse racks or the trash bin if they are empty.
- Restock. Restock workers will use stored boxes to restock shelves.

**Pause game button**
Can be found in the phone.

**Store name**
Can now edit the store name for free from the store expansion section of the phone.

**Animation Popups (Experimental)**
Implemented happy animation when customers get processed at the checkout.

**More info in the main menu**
Added more info to save slots in the main menu.

**Passerby NPCs**
Added passerby npcs to make the area feel more alive.


## Notable bug fixes & improvements

- Reworked tooltip position and size to be less invasive to the UI.

- Adjusted leveling curve to be less harsh.

- Added visual representation to the warehouse rack interaction point when moving the furniture around.

- Customers prioritize desks manned by a cashier employee.
